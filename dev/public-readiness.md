## 功能修正与证据

- 扫荡次数、焕发限制、属性和英雄模式原先分别覆盖同一 `custom_action_param`，后面的值会丢失前面的设置。改为独立设置节点，并在 Agent 当前上下文中读取；本地原生 MaaFramework 测试验证非默认值、0 次与属性同时传递。
- MaaFramework 省略的动作参数可能导出为 JSON null，统一按无参数动作处理，避免影响活动及通行证入口。
- 已领取免费金币正常跳过；售罄字符兼容游戏字体 OCR 的“售馨”，避免点无效商品后误报确认框缺失。异常恢复不再用“取消按钮不存在”掩盖原始错误。
- 活动按钮实际“一键领取”被 OCR 为“键领取”，在已识别目标页与按钮颜色双重约束下兼容。实机领取积分 4480→4680，共 200，之后识别无可领目标并返回大厅。
- 商店实机预览成功：免费金币已领取、绿锤和传说觉醒石售罄均跳过，强化锤识别为 1000 金币并取消，返回大厅。没有执行本轮付费游戏货币购买。
- 80 项本地单元/原生参数测试通过，引用检查 233 节点、21 任务、13 Agent 动作。

其余免费日常实机复验 8/8 成功：大厅、签到与灵魂点、公会、邮箱、好友、通用免费扫荡、日常与小公主宝箱检查、通行证。觉醒及忒提斯当天免费次数已用完，正确跳过；通行证无可领目标正常返回，没有再次扣体力。
