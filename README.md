# 坎公骑冠剑助手 v0.3.0

MaaFramework 5.12.3 / MFAAvalonia 2.16.2，国服B站包 `com.bilibili.snake`。2026-10-14 在MuMu、1280×720上验证。

## 使用

启动MuMu，双击本目录 `run_gui.bat` 或工作目录「坎公骑冠剑助手」快捷方式。设备选择 `127.0.0.1:16384` 后开始任务。
首次设备发现可能晚于自动连接，此时点击重新连接。默认勾选8项日常，可选体力扫荡默认关闭，按需勾选和设置。
不要同时用M9A、GUI、CLI或开发工具操作同一实例。M9A仅供参考，本项目始终使用自身GUI完整路径。
Agent使用本机 `C:/Python314/python.exe` 和标准库；换电脑需修改 `interface.json` 的 `agent.child_exec`、ADB/MuMu路径。

## 扫荡

四类体力副本**共用每天10次焕发额度**，实测依次剩余10→9→8→7→6。默认仅焕发，实际次数取配置与剩余额度的较小值，额度为0跳过。
无焕发选项的普通副本会在默认设置下跳过。任务顺序决定额度分配，可拖动调整优先级。关闭仅焕发会继续使用普通体力。
游戏可能使用备用体力；提交前校验当前与备用体力扣除总数为每次10体力，不购买体力。

进化石自动模式从设定属性开始，选择已持有、未满星且累计进化石少于1160的英雄。每扫荡一次重新检查；没有目标时按虚→光→暗→土→火→水循环换属性，不选“未持有”。不会执行英雄进化。
手动目标模式沿用游戏内相应属性齿轮“奖励设置”的英雄，按配置次数刷取，不自动换英雄。可由用户在游戏中指定目标。
实测虚属性目标选择和单次扫荡；刷满后的切换通过决策测试，尚无本账号恰好刷满的实机样本。
识别不清、费用异常或结果计数不符时失败并保留截图，未知状态不盲点。

## 商店购买

只有开启分类才显示商品设置。数量和本次总预算任一为0时不购买，预算按各商品分别计算；每次只购买1份，重复前重新检查价格和库存。仅支持金币、普通钻石和英雄水晶，付费钻石及现金商品不支持。
传说中的觉醒石、绿锤在本账号缺货，本次未验证补货后的购买。已实机预览体力100钻石、强化锤1000金币，均取消未购买。界面不明或余额变动不符时停止并保存截图。
GUI保留运行；下次用 `run_gui.bat` 启动时自动更新旧任务缓存，保留设备配置和已有顺序。详细实测见 `dev/shop-validation.md`。

## 截图速度与帧率

EmulatorExtras是MaaFramework的模拟器增强截图通道，MuMu通过原生接口取图，省去普通ADB编码传输。
本机各20次：Encode中位数275ms；EmulatorExtras中位数4.07ms，范围3.49～4.92ms。已配置MuMu路径、实例0；输入仍为AdbShell。

- GUI实时视图：实例 `UI.LiveView.RefreshRate=15`，在实时视图设置中可调整。
- 脚本：主资源“识别轮询间隔”50～2000ms，默认100ms，约最多10轮/秒。
- 截图耗时不是整体识别或游戏帧率，OCR、动作等待和渲染都会影响实际频率。Agent按需截图并有限等待。

换模拟器时重新选择支持的截图方式，不支持增强通道可切回Encode。
